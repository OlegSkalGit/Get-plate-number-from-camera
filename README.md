# Get-plate-number-from-camera (ANPR & NVR)

Система відеоспостереження та відеоаналітики для Windows на базі **ONNX Runtime**, **OpenCV** та **FFmpeg** з підтримкою графічних і процесорних прискорювачів (**NVIDIA CUDA**, **DirectML**, **OpenVINO**, **CPU**).

---

## Основні можливості

- **Мультикамерна сітка перегляду:**
  - Підтримка RTSP / HTTP / RTMP / UDP / локальних відеофайлів та вебкамер.
  - Субпотік (`sub_source`) для легкої сітки та основний потік (`main_source`) для аналітики, запису й детального перегляду.
  - Безрамковий інтерфейс головного вікна, збереження позиції, розмірів та стану (`maximized`) усіх вікон.
  - Інтерактивний цифровий зум (ROI) та режим кіоску (`Ctrl+Alt+Shift+Q`).
- **Організація камер у вигляді дерева:**
  - Підтримка вкладених гілок (папок), перетягування (Drag & Drop) камер і гілок для зміни порядку та структури.
  - Груповий запуск/зупинка (`▶ Старт` / `⏹ Стоп`) для окремої камери, гілки або всіх камер.
- **Модулі відеоаналітики (AI):**
  - **Номерні знаки (`plates`):** детекція та OCR розпізнавання автономерів (`best.onnx` + `cct_xs_v2_global.onnx`), трекінг, фільтр різкості, глобальний модуль пошуку номерів по всіх камерах із єдиною часовою шкалою.
  - **Обличчя (`faces`):** біометрична детекція та розпізнавання (`scrfd_face_detector.onnx` + `face_recognizer.onnx`), спільна база осіб, глобальний модуль **Люди** з пошуком по фото, фільтрами та єдиною часовою шкалою.
  - **Люди та транспорт (`people`):** детекція людей і транспортних засобів (`yolo11n.onnx`) з періодичною фіксацією знімків.
- **Відеозапис та архів (`video`):**
  - Прямий запис мережевого потоку без перекодування (`copy` — ~0% CPU).
  - Апаратне кодування (`h264_nvenc`, `hevc_nvenc`, `h264_qsv`, `h264_amf`) або програмне (`libx264`, `libx265`, `mp4v`).
  - Автоматичне очищення застарілих записів.
- **Безпека та багатомовність:**
  - Вхід за паролем (опційно), шифрування посилань на джерела відео (`main_source` / `sub_source`) згідно з паролем, запит пароля при переході в налаштування.
  - Режим **Оператор** (перегляд і live-аналітика без запису на диск) та **Сервер**.
  - Підтримка 57 мов інтерфейсу (`lang/*.json`).

## Швидкий старт (Windows)

### Варіант 1: Автоматичне встановлення одним файлом
1. Завантажте [`0_INSTALL.bat`](0_INSTALL.bat) у порожню папку.
2. Запустіть `0_INSTALL.bat` — скрипт сам завантажить репозиторій, розпакує файли, запустить `1_SETUP.bat` та після встановлення відкриє програму (`3_RUN.bat`).

### Варіант 2: Вручну з репозиторію
1. Клонуйте або розпакуйте репозиторій.
2. Запустіть **`1_SETUP.bat`** — створиться віртуальне оточення `.venv` та встановляться залежності.
3. Запустіть програму:
   - **`3_RUN.bat`** — звичайний запуск.
   - **`2_RUN_DEBUG.bat`** — запуск із консоллю для перегляду логів.
   - **`4_BUILD_exe.bat`** — збірка автономного `.exe` файлу.

## Налаштування прискорення

У розділі **Налаштування → Апаратні ресурси та графіка** доступний майстер автоматичного підбору:
- Визначення оптимального бекенду (`CUDA`, `DirectML`, `OpenVINO`, `CPU`).
- Автоматичне завантаження бібліотек CUDA / cuDNN та моделей у `models/`.
- Вибір оптимального відеокодека та кількості потоків AI/декодування.
